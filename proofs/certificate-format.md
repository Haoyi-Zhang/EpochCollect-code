# Executable certificate contract

The instance is a JSON object with `ports` and a nonempty `tasks` array. Task indices are array positions. Each task has `pair` (two distinct integer endpoints), positive integral `p`, and optional `pred` (earlier indices). Booleans do not count as integers. The parsers allow 2–10,000 endpoints, 1–10,000 tasks, and service up to 10^12; exact optimization additionally requires at most 16 tasks. Pair order is immaterial. Consecutive tasks on the same unordered pair gain a FIFO predecessor edge in both implementations.

A single CLI packet contains `instance` and `certificate`. The planner also emits `spectrum` and `search`, which the feasibility checker does not trust as an optimality certificate. A certificate contains `mode`, integral setup `rho` in [0,10^12], nonempty `epochs`, and `makespan`. Every epoch lists task indices, integral `start` and `end`, and one event per task. Every event has `task`, `start` and `finish`. Epoch task sets partition the instance exactly; all completed prefixes are ideals; distinct pairs in a batch form a matching. Events must equal the independently interpreted earliest-start execution, not merely fit inside a plausible interval. Setup starts only after drain; the first epoch starts at zero and incurs no initial setup. A claimed saturated batch must equal the recursive closure of its pair support. Endpoint intervals and precedence are also checked directly.

For symbolic `broadcast` or `allreduce` instances, `chunks` must be positive and ports×chunks must not exceed 65,536. Every task declares integer `chunk`, `src`, `dst`, `value`, and phase `broadcast` or `reduce`. Endpoints must agree with the physical pair. A broadcast instance cannot declare reduction operations. Missing semantics means an ordinary scheduling instance; present but unknown or null semantics is rejected. Metadata bounds are checked before allocating symbolic storage.

A broadcast starts with token 1 at endpoint zero for each chunk. An Allreduce starts with the singleton bit 1<<endpoint at each endpoint for each chunk. Source values are captured at task start. Finish events are processed before start events sharing a timestamp. Reduction unions disjoint bit sets and rejects a duplicate summand; broadcast copies the captured value. At termination every endpoint must hold token 1 for broadcast or all endpoint bits for Allreduce. This establishes exact symbolic coverage, not floating-point equality, reduction associativity in hardware, memory safety or GPU scheduling behavior.

The stored weighted and scale packets use `certificates`, a map of named alternatives. `verify_results.py` interprets each member. The single-packet CLI format and the multi-certificate archive format are deliberately different and documented rather than silently conflated.

The checker establishes canonical feasible executions under the stated model. It cannot prove that an arbitrary supplied schedule is optimal or that an optical device will complete on time. General theorems are written in `model.md`; finite exactness is cross-checked using the bounded independent assignment enumeration. The model assumes reserved storage and eventual completion. Malicious runtime behavior, arbitrary input denial-of-service resistance, hardware failures and proof-assistant verification are not claimed.
