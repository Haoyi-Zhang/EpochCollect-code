# Third-party sources and tools

No external scientific code, binary, trace, learned model, solver, or paper PDF is bundled in this standalone artifact. Python is used through its standard library; the interpreter is not redistributed. All communication instances are generated from the formulas and selection rules provided here. `external_resources.csv` lists the scholarship actually consulted, the exact available source identifiers and read extent. A publicly readable paper is not assumed to be freely redistributable.

The outer project's `paper/` directory contains the supplied, unmodified IEEEtran class and bibliography style with their original LPPL notices. Those publisher assets are not needed by this standalone repository. No installation or fingerprint report is bundled. Stable arXiv identifiers include the exact scholarly revision consulted; they are source identifiers, not artifact release labels.
